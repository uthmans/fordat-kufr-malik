# Privacy disclosure draft — review before distribution

Drivers explicitly start location sharing. During an active shift, their name,
published business phone number, location, direction, duty, seats and announcements
can be read by passengers through the shared backend. The latest report may remain
as a labelled last-seen report after updates stop. An off-duty publication clears
precise coordinates. Stopping transmission alone does not prove an off-duty report
reached the server, especially without internet.

PINs go to the existing secured authentication endpoint. Opaque session tokens
are kept in platform secure storage. The app does not receive fingerprints,
face templates or the phone's screen-lock code. Native phone unlock protects a
remembered local session; server authorization is still required.

Reservation names, local requests and trip archives are kept on the device.
WhatsApp opens a prepared message; the user decides whether to send it. Sending
that message shares its contents with WhatsApp and the selected driver. A normal
call opens the phone dialler. OS location services and their providers are subject
to the phone's own settings and privacy rules.

Before using this as a published policy, supply the responsible operator's contact
details, confirm retention/deletion procedures, review the backend's operational
logging, and complete the actual Google Play/Apple privacy and background-location
forms. This file is a review draft, not an assertion that store requirements have
been completed.
